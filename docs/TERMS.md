# Terms and Research Disclaimer

This project is an educational and personal research tool, not financial, investment, legal or tax advice.

Model outputs depend on public/provider data, source availability, simplified assumptions and user-selected valuation inputs. Data can be delayed, incomplete, inconsistent or unavailable. DCF values, reverse-DCF outputs and research scores are analytical aids rather than objective forecasts of future returns.

Security coverage depends on the configured upstream data-provider entitlements. A security may therefore be unavailable even when the analyser supports its listing market generically.

Yahoo Finance, Fiscal.ai and SEC data can differ because of timing, accounting classification, reporting definitions, security/share-count treatment and provider methodology. A structured transcript excerpt should be read in its surrounding call context before being used for a consequential investment decision.

Fiscal.ai access and permitted use are governed by the user's own Fiscal.ai account and applicable provider terms. API keys must not be published in the repository.

Version 1.0 uses the canonical research-report interface by default. A controlled unavailable result does not silently invoke the retained legacy analyser. Operators may explicitly select the legacy rollback interface with `USE_LEGACY_UI=true` during the initial release window; this changes the interface only and does not change provider rights, data availability, or the research disclaimer.
